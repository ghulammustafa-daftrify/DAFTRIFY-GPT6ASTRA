02 / THE FRICTION

The documents are rarely the problem. The mess around them is.

Scans, PDFs, spreadsheets, versions, names, dates and supporting records arrive in different shapes. Someone still has to make the state of the set obvious before another person can review it.

Scattered inputs

Different formats, folders and naming conventions.

Version drift

The same fact can move between records.

Hidden exceptions

Missing or conflicting items need deliberate attention.

Manual rework

Comparison and packaging consume specialist time.
